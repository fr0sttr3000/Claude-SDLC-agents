# Known Issues — {PROJECT}

> Операционный реестр известных дефектов, ушедших в прод (KEDB).
> Файл создаётся s0-tracker при инициализации проекта.
> Этот файл читает **s6-sre во время инцидента** — ключ поиска = Detection signal / имя алерта.
> Дедлайн, агент-исполнитель и одобрение фикса — НЕ здесь, а в `tech-debt.md` (поле «→ tech-debt»).

---

## Правила записи

- Дефект попадает сюда ТОЛЬКО если выполнены ВСЕ условия:
  - severity ≤ S3 (или security Low/Medium по CVSS) — блокирующие S1/S2 в прод не уходят;
  - `Impact` = user-facing (есть наблюдаемое в проде проявление);
  - определён `Detection signal` (как увидим, что дефект проявился).
- Иначе дефект/долг живёт обычной строкой в `tech-debt.md` (только планирование, без мониторинга).
- Каждая запись обязана иметь: Trigger, Impact, Detection signal, Workaround, ссылку `→ tech-debt`.
- `Auto-remediation` — опционально (только где автоматизируемо); если нет — явно «нет».
- Дублировать дедлайн/исполнителя из `tech-debt.md` ЗАПРЕЩЕНО — только ссылка (единый источник правды).
- Имя алерта = id записи (KI-NN) = имя runbook'а (SRE-runbook-KI-NN.md) — единый join-ключ.

---

## Жизненный цикл

- **Создание:** s5-qa на go/no-go (Gate 5) — дефект промотируется в known issue.
- **Gate 7:** для каждой записи `OPEN` алерт настроен и протестирован (fire drill), runbook существует.
- **Закрытие:** фикс зарелижен → статус `FIXED` (дата, версия) → снять алерт + runbook →
  запись в CHANGELOG → закрыть связанный TD в `tech-debt.md`.

## Формат записи

```
### KI-[N] — [краткое название дефекта]
- Severity: S3            (для security — CVSS x.x вместо S-шкалы)
- Trigger: при каком условии/нагрузке/вводе проявляется
- Impact / blast radius: что видит пользователь, на какую долю трафика/юзеров
- Detection signal: конкретное условие (метрика/лог-сигнатура); имя алерта = KI-[N]
- Auto-remediation: автодействие + порог + кулдаун — ИЛИ «нет (только ручной обход)»
- Workaround: ручной обход кратко (пошаговые детали — в runbook)
- Runbook: SRE-runbook-KI-[N].md
- → tech-debt: TD-[M]     (там дедлайн фикса и Patch SLA)
- Status: OPEN | FIXED (дата, версия)
```
