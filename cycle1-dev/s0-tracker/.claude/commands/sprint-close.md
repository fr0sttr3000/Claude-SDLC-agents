---
description: Закрыть текущий спринт с итогами выполненных и невыполненных задач
---

Закрой текущий спринт для проекта $ARGUMENTS.

Шаги:
1. Прочитай current-sprint.md:
   $SDLC_PROJECTS_DIR/$ARGUMENTS/tracking/current-sprint.md
   Если активного спринта нет — сообщи и останови.

2. Прочитай файл спринта (sprint-NN.md) и подсчитай:
   - Всего задач запланировано / SP запланировано
   - DONE: N задач, M SP
   - IN_PROGRESS: N задач (→ перенести в следующий спринт)
   - TODO: N задач (→ вернуть в backlog или перенести)
   - BLOCKED: N задач (→ перенести с пометкой)
   - CANCELLED: N задач

3. Выведи итоговый отчёт спринта:
```
╔══════════════════════════════════════════════════════╗
║  ИТОГ СПРИНТА N — Проект: PROJECT
╠══════════════════════════════════════════════════════╣
║  Цель спринта: [цель]
║  Период: YYYY-MM-DD → YYYY-MM-DD
╠══════════════════════════════════════════════════════╣
║  ✅ ВЫПОЛНЕНО: N задач (M SP)
║     ✓ T-001 [3SP] Название
║     ✓ T-002 [5SP] Название
╠══════════════════════════════════════════════════════╣
║  ❌ НЕ ВЫПОЛНЕНО: N задач (M SP)
║     → T-003 [2SP] Название  [IN_PROGRESS → след. спринт]
║     ○ T-004 [3SP] Название  [TODO → backlog]
║     ✗ T-005 [5SP] Название  [BLOCKED: причина → след. спринт]
╠══════════════════════════════════════════════════════╣
║  Velocity: X SP  |  Выполнено: N% задач  |  N% SP
╚══════════════════════════════════════════════════════╝
```

4. Обнови sprint-NN.md: добавь секцию "## Итог" с данными выше, установи status: CLOSED.

5. Перенеси незакрытые задачи:
   - IN_PROGRESS и BLOCKED → в следующий спринт (если он создан) или backlog с пометкой
   - TODO → обратно в backlog со статусом TODO

6. Обнови backlog.md для перенесённых задач.

7. Очисти current-sprint.md (или запиши "Нет активного спринта").

8. Сохрани в:
   $SDLC_PROJECTS_DIR/$ARGUMENTS/tracking/sprints/sprint-NN.md

ОБЯЗАТЕЛЬНО: в конце вывести итоговый task board по формату из CLAUDE.md (показывая все задачи закрытого спринта с финальными статусами).
