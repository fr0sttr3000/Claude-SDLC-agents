---
description: Создать или переключить явно названную branch после preview
---

Аргументы: project и exact branch name. Покажи repository root, current branch, status,
существует ли target локально/на remote, и точную команду. При незакоммиченных изменениях
объясни риск; не stash/commit автоматически. Создай или переключи branch только после
явного подтверждения. Не удаляй ветки, не меняй upstream и не публикуй branch этой командой.
