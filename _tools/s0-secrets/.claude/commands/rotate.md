---
description: Ротировать выбранную запись секрета в pass без вывода значений
---

Сначала прочитай каноническую policy в
`$SDLC_VAULT/_agents/_standards/security.md#Хранение-секретов`.

Для `$ARGUMENTS`:

1. Разреши exact существующий `pass` entry reference и покажи только reference.
2. Получи подтверждение выбранного entry; при неоднозначности верни `BLOCKED`.
3. Для генерируемого пароля используй интерактивный `pass generate -i`; для внешнего token/key —
   интерактивный `pass insert -f`. Не принимай новое значение через chat или argv.
4. Подтверди только reference и напомни отозвать прежнее значение в исходной системе, если это
   применимо.

Не показывай старое или новое значение и не создавай plaintext-файлы.
