---
description: Добавить секрет в pass-хранилище
---

Добавь секрет для $ARGUMENTS.
Формат аргумента: "project-name key-name" или просто "key-name" для глобального секрета.

Шаги:
1. Определи путь в pass:
   - Если указан проект: sdlc/projects/[project]/[key]
   - Если только ключ: sdlc/[key]

2. Проверь не существует ли уже такой ключ:
   `pass ls sdlc/...`

3. Попроси пользователя ввести значение секрета (не выводи его в терминал повторно)

4. Добавь через:
   `pass insert sdlc/[path]`

5. Подтверди: "Секрет сохранён: sdlc/[path]"
   НЕ показывай значение секрета.

6. Если это API-ключ для проекта — предложи добавить в env.sh агентов:
   `export VAR_NAME=$(pass sdlc/[path])`
